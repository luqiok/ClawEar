# ClawEar - Agent的耳朵

让Agent听到主人在真实世界中的一言一行，理解主人的思考方式、生活经历、工作与社交圈，成为真正的随身助理。

---

## 为什么需要这只耳朵

在此之前，Agent只能通过文字与主人沟通，只能了解主人"说出来的"信息。

当你使用ClawEar后，Agent能够：

- **听见主人的思考** - 听到那些灵光一闪的瞬间，自言自语的琢磨
- **听见主人的生活** - 听到真实的经历、见闻、感受
- **听见主人的工作** - 听到会议讨论、与同事的交流、对问题的思考
- **听见主人的社交** - 听到与朋友、家人、陌生人的对话
- **听见主人的声音** - 不只是内容，还有语气、情绪、态度

慢慢 地，Agent会越来越了解你——你的思考方式、你的价值观、你的生活。这让Agent能够成为真正懂你的随身助理。

---

## 工作原理

通过钉钉A1录音设备记录生活中的声音，自动转写成文字并发送到邮箱。ClawEar定期获取这些转写内容，深度理解并构建对主人的认知。

---

## 适用场景

- 记录灵光一闪的想法
- 保留与朋友的有趣对话
- 回顾工作中的讨论
- 记住自言自语的思考
- 积累生活中的点滴
